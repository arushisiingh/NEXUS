# Thermal result provenance

These files were generated by the C++17 `nexus-thermal-export` executable from the default assignment parameters. They are not hardcoded frontend data.

- `temperature_vs_position.csv`: N=80 nodal FEM and analytical temperatures.
- `fem_analytical_comparison.csv`: N=80 midpoint interpolation, analytical temperature, and absolute error.
- `mesh_convergence.csv`: N=10, 20, 40, 80 maximum midpoint errors.
- `temperature_comparison.svg`: N=80 FEM versus analytical plot.
- `mesh_convergence.svg`: generated plot of maximum midpoint error versus mesh size.
